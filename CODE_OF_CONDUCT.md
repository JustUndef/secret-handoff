# Code of conduct

Everyone participating in this project is expected to treat others respectfully, regardless of background, identity, experience, or choice of development tools.

- Give constructive, specific feedback and assume good intent while addressing harmful behavior.
- Discuss the work and its evidence. Disagreement is welcome; harassment, threats, personal attacks, discrimination, and sexualized conduct are not.
- Respect privacy. Do not publish another person's private information, credentials, or communications without permission.
- Keep project spaces useful and free of spam and unrelated promotion.

This applies to issues, pull requests, reviews, and other project spaces. Maintainers may edit or remove inappropriate content, close discussions, or restrict participation, considering the circumstances and severity.

Report conduct concerns privately using a contact method explicitly provided by the maintainer. If no private channel is available, request one without posting personal details publicly. Security vulnerabilities follow [SECURITY.md](SECURITY.md).
